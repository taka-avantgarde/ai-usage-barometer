## ⚡ التثبيت — الصق هذا السطر في الطرفية

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/taka-avantgarde/ai-usage-barometer/main/install-app.sh)"
```

هذا هو التطبيق. بلا Homebrew وبلا Xcode. يتطلب macOS 13 أو أحدث. في أول تشغيل يسألك أين يريد أن يستقر — شريط القوائم أو أيقونة Dock أو شريط عائم — ويمكنك تغيير ذلك من قائمته في أي وقت.

## عنصر واحد في شريط القوائم

يتشارك Claude و Codex و Gemini عنصرًا واحدًا يفصل بينهما خط رفيع. الأشرطة على نمط البطارية: **الجزء الممتلئ هو السعة المتبقية**، والذيل المنقّط هو ما استُهلك. النسب المئوية تمثل المتبقي أيضًا.

```text
5h ███░·  1w ██░░·  │  5h ████·  1w ███░·  │  5h ████·  1w ███░·
└──── Claude ────┘     └───── Codex ─────┘     └──── Gemini ────┘
```

يُرسم شريط القوائم كصورة متجهية ليحتفظ كل خدمة بلونها داخل عنصر واحد. وإن تعذّر ذلك يُستخدم نص عادي تلقائيًا.

تستخدم اللوحتان ألوانًا مشبعة وعالية التباين: يستخدم Claude البرتقالي، ويستخدم
Codex السماوي. عند بقاء 11–30% يمتزج لون التحذير بالبرتقالي، وعند بقاء 10% أو
أقل يمتزج اللون الحرج بالأحمر الزاهي. يحتفظ Codex بالأزرق في كلا المزيجين:

## الإعدادات

افتح القائمة واختر **⚙ Display settings**. تبقى لوحة الإعدادات مفتوحة لتغيير عدة خيارات متتالية من دون أن تُغلق بعد كل نقرة، وتُطبّق التغييرات فورًا.

واجهة الملحق باللغة الإنجليزية فقط، بينما تظل وثائق GitHub هذه متاحة بـ14 لغة.

| الإعداد | الأثر |
|---|---|
| **Claude** (`ON` / `OFF`) | إظهار أو إخفاء Claude بالكامل (ينطبق على `5h` و `1w`) |
| **Claude `5h`** + **`%`** | إظهار أو إخفاء نافذة 5 ساعات ونسبتها المئوية |
| **Claude `1w`** + **`%`** | إظهار أو إخفاء نافذة أسبوع واحد (7d) ونسبتها المئوية |
| **Codex** (`ON` / `OFF`) | إظهار أو إخفاء Codex بالكامل (ينطبق على `5h` و `1w`) |
| **Codex `5h`** + **`%`** | إظهار أو إخفاء نافذة 5 ساعات (Codex 5h) ونسبتها المئوية |
| **Codex `1w`** + **`%`** | إظهار أو إخفاء نافذة أسبوع واحد (Codex 7d) ونسبتها المئوية |
| **Gemini** (`ON` / `OFF`) | إظهار أو إخفاء Gemini بالكامل (ينطبق على `5h` و `1w`) |
| **Gemini `5h`** + **`%`** | إظهار أو إخفاء نافذة 5 ساعات (`5h`) ونسبتها المئوية |
| **Gemini `1w`** + **`%`** | إظهار أو إخفاء نافذة أسبوع واحد (`1w` / 7d) ونسبتها المئوية |
| **الموضع** (`Menu bar` / `Dock icon` / `Floating bar`) | اختر أي مزيج من مواضع العرض الثلاثة |
| **فاصل التحديث** (`1m` / `3m` / `5m`) | دقيقة واحدة أو 3 دقائق أو 5 دقائق |

عند إخفاء كل المؤشرات يبقى عنصر محايد `AI …` لفتح الإعدادات. يتحدد اللون بالأشرطة الظاهرة فقط. تُحفظ الإعدادات في `~/.cache/claude-codex-bar/` وتبقى بعد التحديث.

عند إلغاء تحديد Claude أو Codex، يتوقف تحديث بيانات ذلك المساعد. تبقى إعدادات 5h و7d والنسبة مموهة وغير قابلة للتفاعل، وتُستعاد قيمها السابقة عند إعادة التفعيل.

إذا أُلغيت نافذتا 5h و7d معًا لخدمة ما، تُخفى الخدمة وأخطاؤها بالكامل ولا يُستعلم عن مصدر بياناتها.

يتحقق التطبيق والمكون الإضافي من GitHub Releases تلقائيًا كل 15 دقيقة ويتم التحديث في الخلفية عند نشر إصدار جديد.

## التطبيق — اختر مكانه

شريط القوائم ليس متاحًا دائمًا. على بعض أجهزة Mac يوضع عنصر الحالة خارج الشاشة
ولا يُرسم أبدًا، وبجوار النتوء قد لا تكون هناك مساحة أصلًا. يضع التطبيق المقاييس
نفسها في المكان الذي تختاره.

| المكان | الوصف |
|---|---|
| **شريط القوائم** | عنصر حالة خاص بالتطبيق، في سطر واحد |
| **أيقونة Dock** | تتحول أيقونة Dock نفسها إلى مقياس. لا تستهلك أي مساحة من الشاشة |
| **شريط عائم** | شريط صغير يبقى في المقدمة دائمًا. اسحبه إلى أي مكان |

الثلاثة مستقلة، فاختر أي تركيبة. انقر بالزر الأيمن على الشريط أو على أيقونة
Dock أو على عنصر شريط القوائم لفتح الإعدادات: تشغيل كل خدمة أو إيقافها،
النِّسب المئوية، مكان العرض، و **Details…** للوحة التي تعرض أوقات التجديد.

إيقاف أي مقياس يعيد المساحة: يتقلّص العنصر ليطابق ما تبقّى، ويستفيد شريط القوائم من الفارق.

السهم البرتقالي يعني أن هناك تحديثًا بانتظارك، و **Update to vX.Y.Z** في القائمة نفسها يثبّته في مكانه.

سطر واحد، ودون حاجة إلى Xcode. نظام macOS 13 أو أحدث.

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/taka-avantgarde/ai-usage-barometer/main/install-app.sh)"
```

التطبيق موقَّع ومُوثَّق من Apple، لذا يفتح مباشرة بعد التنزيل، بلا تحذير وبلا نقر بالزر الأيمن.

أو شغّله من المصدر، وهذا يتطلب Xcode:

```bash
git clone https://github.com/taka-avantgarde/ai-usage-barometer.git
cd ai-usage-barometer/app && swift run
```

## مصادر البيانات

تُقرأ بيانات **Claude** من نقطة OAuth `api.anthropic.com/api/oauth/usage` باستخدام الرمز الذي يحفظه Claude Code في سلسلة مفاتيح macOS (`Claude Code-credentials`، وإلا `~/.claude/.credentials.json`). لا يُكتب شيء في أي منهما، ولا يغادر الرمز جهازك إلا في الطلب المرسل إلى Anthropic. عند أول تشغيل اختر **السماح دائمًا**.

تُخزَّن النتائج مؤقتًا طوال الفاصل، فلا تُستدعى النقطة أكثر من مرة واحدة لكل فاصل. وإذا فشل التحديث تبقى آخر قراءة صحيحة معروضة.

يتم قراءة **Codex** من المساعد المحلي `codex-usage.sh` في `.ai-usage-barometer/`. يتتبع كلاً من نافذتي `5h` و `1w` (`7d`) بالترتيب `5h → 1w` دائمًا (حتى في حال عدم استهلاك نافذة الـ 5 ساعات بعد).

يتم قراءة **Gemini** من المساعد المحلي `gemini-usage.sh` المرفق مع التطبيق. يدعم كلاً من Antigravity Desktop App 2.0 و Antigravity IDE، ويقرأ نافذتي `5h` و `1w` محليًا بأمان عبر Connect RPC (`RetrieveUserQuotaSummary` / `GetUserStatus`) و SQLite (`state.vscdb`) والذاكرة المؤقتة، دون إجراء مكالمات API خارجية أو كتابة بيانات اعتماد.

## حل المشكلات

**يظهر تحذير Claude.** افتح القائمة المنسدلة لمعرفة السبب. تعني رسالة *Sign in to Claude Code again* أن رمز OAuth قد انتهت صلاحيته — أعد المصادقة عبر أداة سطر أوامر Claude Code أو إضافة بيئة التطوير. **هذا ليس تطبيق Claude لسطح المكتب**: تسجيل الدخول في Claude.app لا يجدّد هذا الرمز. أما *Rate limited* فتُحل تلقائيًا؛ تنتظر الإضافة 15 دقيقة وتعرض الوقت المتبقي.

**يظهر تحذير Codex.** المساعد مفقود أو لم يُنتج Codex بيانات بعد. أعد تشغيل المثبّت ثم استخدم Codex CLI مرة واحدة.

**يعرض Gemini تحذيرًا.** لم يتم تشغيل Antigravity بعد أو أن المساعد المحلي ينتظر البيانات. شغّل Antigravity Desktop أو Antigravity IDE.

**تختلف الألوان بين شريط القوائم والقائمة المنسدلة.** قد يعامل macOS شريط القوائم الشفاف كفاتح بينما القوائم داكنة. يُستخدم الرسم المتجهي بلونين عند توفر Python، ولا يُستخدم النص بلون واحد إلا عند غياب Python.
