# 🎚️ AI Usage Barometer

## ⚡ التثبيت — الصق هذا السطر في الطرفية

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/taka-avantgarde/ai-usage-barometer/main/install.sh)"
```

يعمل الأمر نفسه على أجهزة Mac مع Homebrew أو بدونه. يثبّت فقط ما هو مفقود: Homebrew و`jq` و SwiftBar والإضافة ومساعديها المحليين. إعادة التشغيل آمنة، واستخدم السطر نفسه للتحديث.

## عنصر واحد في شريط القوائم

يتشارك Claude و Codex عنصرًا واحدًا يفصل بينهما خط رفيع. الأشرطة على نمط البطارية: **الجزء الممتلئ هو السعة المتبقية**، والذيل المنقّط هو ما استُهلك. النسب المئوية تمثل المتبقي أيضًا.

```text
5h ███░·  7d ██░░·  │  7d ████·
└──── Claude ────┘     └─ Codex ─┘
```

يُرسم شريط القوائم كصورة متجهية ليحتفظ كل خدمة بلونها داخل عنصر واحد. وإن تعذّر ذلك يُستخدم نص عادي تلقائيًا.

تستخدم اللوحتان ألوانًا مشبعة وعالية التباين: يستخدم Claude البرتقالي، ويستخدم
Codex السماوي. عند بقاء 11–30% يمتزج لون التحذير بالبرتقالي، وعند بقاء 10% أو
أقل يمتزج اللون الحرج بالأحمر الزاهي. يحتفظ Codex بالأزرق في كلا المزيجين:

| المرحلة | الاستهلاك | Claude | Codex |

## الإعدادات

افتح القائمة واختر **⚙ إعدادات العرض**. تبقى لوحة الإعدادات مفتوحة لتغيير عدة خيارات متتالية من دون أن تُغلق بعد كل نقرة، وتُطبّق التغييرات فورًا.

| الإعداد | الأثر |
|---|---|
| إظهار Claude | إظهار Claude أو إخفاؤه |
| إظهار Claude 5h | إظهار نافذة الخمس ساعات أو إخفاؤها |
| نسبة Claude 5h | إظهار نسبتها أو إخفاؤها |
| إظهار Claude 7d | إظهار نافذة السبعة أيام أو إخفاؤها |
| نسبة Claude 7d | إظهار نسبتها أو إخفاؤها |
| إظهار Codex | إظهار Codex أو إخفاؤه |
| إظهار Codex 5h | إظهار نافذة الخمس ساعات أو إخفاؤها عند توفرها |
| نسبة Codex 5h | إظهار نسبة الخمس ساعات أو إخفاؤها |
| إظهار Codex 7d | إظهار نافذة السبعة أيام أو إخفاؤها |
| نسبة Codex 7d | إظهار نسبة السبعة أيام أو إخفاؤها |
| فاصل التحديث | ١ أو ٣ أو ٥ دقائق |
| اللغة | ١٤ لغة، وتتبع macOS افتراضيًا |

عند إخفاء كل المؤشرات يبقى عنصر محايد `AI …` لفتح الإعدادات. يتحدد اللون بالأشرطة الظاهرة فقط. تُحفظ الإعدادات في `~/.cache/claude-codex-bar/` وتبقى بعد التحديث.

عند إلغاء تحديد Claude أو Codex، يتوقف تحديث بيانات ذلك المساعد. تبقى إعدادات 5h و7d والنسبة مموهة وغير قابلة للتفاعل، وتُستعاد قيمها السابقة عند إعادة التفعيل.

إذا أُلغيت نافذتا 5h و7d معًا لخدمة ما، تُخفى الخدمة وأخطاؤها بالكامل ولا يُستعلم عن مصدر بياناتها.

يفحص الملحق GitHub Releases مرة واحدة يوميًا كحد أقصى. عند توفر تحديث من المشغّل يظهر إشعار في القائمة والإعدادات مع ملاحظات الإصدار وزر **التحديث الآن**.

## مصادر البيانات

تُقرأ بيانات **Claude** من نقطة OAuth `api.anthropic.com/api/oauth/usage` باستخدام الرمز الذي يحفظه Claude Code في سلسلة مفاتيح macOS (`Claude Code-credentials`، وإلا `~/.claude/.credentials.json`). لا يُكتب شيء في أي منهما، ولا يغادر الرمز جهازك إلا في الطلب المرسل إلى Anthropic. عند أول تشغيل اختر **السماح دائمًا**.

تُخزَّن النتائج مؤقتًا طوال الفاصل، فلا تُستدعى النقطة أكثر من مرة واحدة لكل فاصل. وإذا فشل التحديث تبقى آخر قراءة صحيحة معروضة.

يُقرأ **Codex** من المساعد المحلي `codex-usage.sh` الذي يضعه المثبّت في `~/SwiftBar/.ai-usage-barometer/`. نوافذه ديناميكية.

## حل المشكلات

**يظهر تحذير Claude.** لم يُعثر على عنصر سلسلة المفاتيح. سجّل الدخول إلى Claude Code على هذا الجهاز ثم اضغط **تحديث الآن**.

**يظهر تحذير Codex.** المساعد مفقود أو لم يُنتج Codex بيانات بعد. أعد تشغيل المثبّت ثم استخدم Codex CLI مرة واحدة.

**تختلف الألوان بين شريط القوائم والقائمة المنسدلة.** قد يعامل macOS شريط القوائم الشفاف كفاتح بينما القوائم داكنة. يُستخدم الرسم المتجهي بلونين عند توفر Python، ولا يُستخدم النص بلون واحد إلا عند غياب Python.
