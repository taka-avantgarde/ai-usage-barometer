# AI Usage Barometer v0.1.7

This release applies the requested colours to the macOS menu bar itself.

- Claude 5h and 7d are evaluated independently.
- Claude stages: `#b54f02`, `#B85A00`, `#ff7045`.
- Codex stages: `#4F7FA8`, `#0e8ba1`, `#ed5d40`.
- Thresholds: stage 1 = 0–69% used, stage 2 = 70–89% used, stage 3 = 90–100% used.
- The updater installs locally first and fully restarts SwiftBar before publishing the release.
