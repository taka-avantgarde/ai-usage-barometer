# 🎚️ AI Usage Barometer

## ⚡ ติดตั้ง — วางบรรทัดนี้บรรทัดเดียวใน Terminal

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/taka-avantgarde/ai-usage-barometer/main/install.sh)"
```

คำสั่งเดียวกันใช้ได้กับ Mac ทั้งที่มีและไม่มี Homebrew หากจำเป็นจะติดตั้ง Homebrew, `jq`, SwiftBar, ปลั๊กอินรวม และตัวช่วย Claude/Codex ให้อัตโนมัติ

SwiftBar หนึ่งรายการแสดงทั้งสองบริการ **แถบเมนู macOS จะไม่แสดงชื่อ Claude หรือ Codex** Claude ใช้โทนสีส้ม ส่วน Codex ใช้โทนสีน้ำเงิน

```text
5h ███░░  7d ████░  │  7d ███░░
```

## ✅ v0.2.0: แก้ไขปัญหาการกู้คืนทั้งสองข้อแล้ว

- **Claude หลังรีเซ็ต:** หาก Claude ส่งค่า `Warming up`, ค่า 0, ช่วงเวลาเป็น null หรือสแนปช็อตเก่าที่เลยเวลารีเซ็ตแล้ว ปลั๊กอินจะไม่ค้างอยู่ที่ข้อผิดพลาดอีกต่อไป แถบ 5h และ 7d จะกลับมาเป็นสถานะรีเซ็ตแล้ว/กำลังรอ โดยเหลือ 100% และจะถูกแทนด้วยค่าจริงโดยอัตโนมัติในการรีเฟรชที่สำเร็จครั้งถัดไป ไม่ต้องติดตั้งใหม่
- **Codex 5h กลับมาในภายหลัง:** ช่วงเวลาของ Codex จะถูกตรวจจับแบบไดนามิก หาก Codex ส่งช่วงเวลา 300 นาทีกลับมา แถบ `5h` จะถูกเพิ่มโดยอัตโนมัติในการรีเฟรชครั้งถัดไป หากไม่มี จะแสดงเฉพาะช่วงเวลาที่มีจริง เช่น `7d`

เลือก **Refresh now** เพื่อขออัปเดตทันที

## 🎨 สี 3 ระดับแบบอิสระ

แต่ละช่วง 5h หรือ 7d จะถูกประเมินแยกกัน

| ระดับ | ใช้แล้ว | Claude | Codex |
|---|---:|---|---|
| 1 — ปกติ | 0–69% | `#b54f02` | `#4F7FA8` |
| 2 — เตือน | 70–89% | `#B85A00` | `#0e8ba1` |
| 3 — วิกฤต | 90–100% | `#ff7045` | `#ed5d40` |

ส่วนหัวถูกสร้างเป็น PDF เวกเตอร์ขนาดเล็กด้วยเครื่องมือใน macOS จึงไม่ต้องใช้ Xcode Command Line Tools

## การตั้งค่าและรายละเอียด

เมนูแสดงชื่อบริการ การใช้งาน ปริมาณที่เหลือ และเวลารีเซ็ต ใน **Settings** สามารถแสดงหรือซ่อน Claude และ Codex แยกกันได้ โดยจะคงไว้อย่างน้อยหนึ่งบริการ ช่วงรีเฟรชเลือกได้ 1, 3 หรือ 5 นาที

> **Codex 5h:** ปลั๊กอินจะไม่คาดเดาขีดจำกัดที่ไม่มีอยู่ โดยซ่อน 5h จนกว่า Codex จะส่งช่วงเวลา 300 นาทีจริง แล้วจึงเพิ่มให้อัตโนมัติ

ปลั๊กอินแบบแยกเดิมจะถูกย้ายไปยังโฟลเดอร์ช่วยเหลือที่ซ่อนอยู่ เพื่อป้องกันรายการซ้ำโดยไม่ลบไฟล์

## ข้อกำหนดและความเป็นส่วนตัว

- macOS; ตัวติดตั้งจะจัดการ Homebrew, `jq` และ SwiftBar
- ลงชื่อเข้าใช้ Claude Code แล้ว
- เคยใช้ Codex CLI หรือแอป Codex บน Mac
- โทเค็นยืนยันตัวตนจะไม่ถูกพิมพ์หรือคัดลอกไปยังแคช
- อินเทอร์เฟซข้อมูลการใช้งานบางส่วนไม่เป็นทางการและอาจต้องอัปเดตความเข้ากันได้ในอนาคต

## ถอนการติดตั้ง

```bash
curl -fsSL https://raw.githubusercontent.com/taka-avantgarde/ai-usage-barometer/main/uninstall.sh | bash
```
