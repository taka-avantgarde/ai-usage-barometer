# AI Usage Barometer v0.1.8

This release fixes the macOS menu-bar colours themselves.

- Exact per-window colours are rendered into a small transparent PNG.
- Claude 5h and 7d remain independent: `#b54f02`, `#B85A00`, `#ff7045`.
- Codex windows remain independent: `#4F7FA8`, `#0e8ba1`, `#ed5d40`.
- Removes the 24-bit ANSI path that appeared black and turned the separator green in SwiftBar.
- Keeps the dropdown text colours and Settings behaviour unchanged.
